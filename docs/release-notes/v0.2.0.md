## 新功能
- 可以直接在 Cellar 里新建角色卡、世界书和预设：点工作区右上角的「+」，写好后在检查栏点「发布到 …」放进酒馆。
- 检查栏新增「撤回」「取消撤回」和「撤销当前的修改」，改错了随时退回去。工作区里的项目右键也能找到这些操作。
- 设置里可以「检查更新」：只看作者正式发布的版本，并显示每个新版本的更新说明。安装版可以直接下载并重启安装。
- 设置里新增「版本历史」：显示历史占用了多少空间，可以一键「压缩历史」；默认开启自动清理，超过 50 MB 时自动压缩，不再使用的中间状态 30 天后自动删除（两个数值都可以改）。
- 没有打开任何项目时，会显示一个空白的工作区页面，并附上几句小提示。

## 改进
- 预设工坊：始终四列显示，对比时可以直接在内容框里修改并高亮差异；预设可以搜索着选；收藏会立即保存。
- 预设编辑器和预设工坊里的提示词条目可以复制和删除。
- 版本历史默认打开上次查看的内容，草稿里的项目点一下就能跳到它自己的历史。
- 工作区文件很多时，打开得更快，切换项目也更流畅。
- 「从工作区移除」改为在原地确认，并说明哪些内容会保留。
- Studio 没有运行时，酒馆里的 Cellar Link 会安静地等待重连，不再反复在控制台刷日志。

## 修复
- 修复移除项目后，点「工作区」按钮没有反应的问题。
- 移除项目或关掉最后一个标签后，会停在当前页面或空白工作区页，不再跳到资料库。
- 修复名字很长的资料项会让版本记录在 Windows 上无法被 git 读取的问题（升级后自动处理，不需要手动操作）。

## 升级须知
- 酒馆里的 Cellar Link 请在「扩展 → 管理扩展」中更新到最新版。
