## 新功能
- **在 Cellar 里改名**：角色卡和世界书可以直接在 Cellar 里改名（检查栏「文件位置」→「改名…」）。改角色名时，酒馆里的聊天记录、标签、作者注释、附加世界书、群组成员都会跟着走，和在酒馆里改名效果一样；世界书和卡同名时可以勾选一起改，卡会自动指向改名后的世界书。工作区里的文件夹和版本历史也跟着换名。
- **在 Cellar 里换头像**：卡片编辑器头像下面有「更换头像…」，选一张图片（PNG / JPG / WebP 都行），会自动裁成正方形再上传到酒馆。卡片内容不变，不用重新同步。
- **项目文件夹**：一张卡和它的世界书可以放进同一个文件夹（比如「诡异复苏」文件夹里放卡和世界书），不用再分散在「角色」「世界书」两处。新建、取出时可以选项目；已有的项右键「移到项目…」随时挪，同步状态、标签和历史都跟着走。侧栏按项目分组显示。
- **导入文件夹**：别人发给你的、或者你备份的 Cellar 格式文件夹，可以用「导入文件夹…」一键复制进工作区。
- **查看差异再决定**：显示「本地有修改」或「酒馆有修改」时，点「查看差异」就能看到具体改了哪里，看完直接点「同步」或「取回」。
- **差异只看改动的地方**：版本历史里的对比默认只显示改动的那几行和前后几行，没改的部分折叠起来，点一下就能展开。想看整段的话，打开「完整文件」开关（会记住你的选择）。
- **新建角色时顺便建世界书**：「+」新建角色可以勾选「同时新建世界书」；发布到酒馆时也可以勾选「连同链接的世界书一起发布」。
- **同名时可以直接绑定**：发布时酒馆里已经有同名的卡或世界书，Cellar 不会覆盖它，而是让你选「绑定到它」或「换个名字」。没发布过的项也可以从列表里挑一个酒馆里已有的来绑定。

## 改进
- 在酒馆里切换聊天不会再让卡显示「酒馆有修改」，也不会再因此要求先取回才能改名。
- 移动项目时如果中途出错，会整个退回原样，不会出现标签、已推送版本对不上的情况。
- 改名时酒馆网页反应慢导致超时，Cellar 会再确认一次；酒馆其实已经改好了的话，会自动跟上新名字。

## 修复
- 修复在工作区里删掉角色卡的某个字段后，同步回酒馆时旧内容又回来的问题。
- 修复手写的世界书新条目在同步后编号可能变化、导致定时效果错乱的问题。
- 修复卡片编辑器窄的时候，头像上沿被标签栏挡住的问题。
- 修复移走或移除最后一项后，空的项目文件夹还留在工作区里的问题。
