## 新功能
- **存档可以只存几项**：版本历史里的「记录版本」就是存档。现在不用把所有改动一次存完，草稿里每一项前面都有勾选框（默认全选），只勾想存的那几项就行，没勾的改动会继续留在草稿里，下次再存。只看某一项的历史时，按钮直接是「存档这一项」。
- **说明随时能改**：存档后觉得说明写得不好，在版本详情里点「修改说明」就能改，存档本身不会变。
- **标签贴在某一项上**：标签就是给某一项的存档起个名字（比如 v1.0），方便以后找到、推送。不同的角色卡、世界书可以各有自己的 v1.0，互不打架。给某一项打标签时，先在左上角选中这一项；标签上的 × 可以删掉它。
- **预设工坊可以交换来源和目标**：顶栏「对比模式」旁边多了「交换来源与目标」按钮，一点就把左右两边的预设对调。如果还有没保存的修改，会先提醒你保存或取消。

## 改进
- 版本历史页顶部的说明改成了大白话，讲清楚草稿、存档、标签、恢复、推送分别是什么。各页面顶部的说明文字现在占满一整行，不再挤在左边。
- 预设工坊：
  - 来源和目标都有「在预设编辑器中打开」按钮，放在预设选择栏前面。
  - 选择历史版本改成选择栏后面的小图标按钮，只有这个预设有历史版本时才出现；正在看历史版本时图标会亮起。
  - 预设选择栏和搜索框现在会占满整行，名字长的预设也能看清了。

## 修复
- 草稿上「记录并打标签」（现在叫「存档并打标签」）会忽略你在输入框里写的说明，现在会用上。
- 用标签推送时，只推送带这个标签的项，不会把同一个存档里其他绑定了该酒馆的项也一起推过去。

## 升级须知
- 酒馆里的 Cellar Link 请在「扩展 → 管理扩展」中更新到最新版（TauriTavern 同样需要更新）。
- 以前打过的标签会在第一次启动新版时自动转成「属于某一项」的标签：那个存档改过哪几项，这几项就各得到一个同名标签。之后在工作区里用 git 命令打的标签不再显示，请在 Studio 的版本历史里打标签。
