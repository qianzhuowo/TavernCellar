## 修复
- 修复在版本历史里只想推送一个资料项（比如一张角色卡）时，会把同一版本里其他绑定了该酒馆的项也一起推送、并固定在这个版本的问题。现在只看一项时只推送这一项；看「全部资料项」时，只推送这个版本改过的项，按钮上会写明要推送几项。
- 推送到酒馆时如果和酒馆断了连接，失败原因会说明断在哪一步（推送前读取时断开的，酒馆里没有被改动），失败的项旁边多了「重试」按钮。
- 修复世界书推送中途断开后，再次推送可能被误报为「酒馆里有新的修改」的问题。

## 升级须知
- 酒馆里的 Cellar Link 请在「扩展 → 管理扩展」中更新到最新版（TauriTavern 同样需要更新）。
- 如果之前误推送过，误推送的项会显示 📌（固定在那个版本）。请在同步页或检查栏点「跟随最新」，恢复正常同步。
