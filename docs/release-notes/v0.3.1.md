## 修复
- 修复在角色卡编辑器里打字时（比如在「第一条消息」里），页面一下跳到「角色描述」、一下又跳回来的问题。现在边打字边保存，页面会停在原处；展开的「其他开场」也不会再自己收起来。
- 修复工作区里项目比较多时，正在编辑的卡偶尔弹出「文件在别处被修改」的问题（其实就是你自己刚保存的内容）。
- 修复从工作区移除的项目一直挂在版本历史「草稿」里、显示成没存档修改的问题。现在移除后会自动存档一个版本「从工作区移除「名称」」，其他项目没存档的修改不受影响，照样留在草稿里。以前移除、还留在草稿里的项目，升级后第一次启动时会自动这样处理。

## 改进
- 酒馆开着、但里面的 Cellar Link 还没连上时推送，提示会直接告诉你该怎么做：切到酒馆页面，它会自动重连（或在扩展设置里点「连接」），连上后再推送；或者先关掉酒馆，再离线推送。酒馆开着的时候不能直接改它的文件，不然它会用自己内存里的旧内容盖回去。
- Cellar Link 连不上伴侣程序时，后台重试从每 5 分钟一次改成每 1 分钟一次，先开酒馆、后开 Cellar Studio 也能更快连上。
